# Vimwiki 명령어 (simple) 

오늘자 diary 생성

```vim
:VimwikiMakeDiaryNote
```

* `diary/2026-03-02.md` 파일이 생성됨.

---

Diary Index 열기

```vim
:VimwikiDiaryIndex
```

---

현재 파일을 참조하는 페이지 목록 

```vim
VimwikiBacklinks
```
